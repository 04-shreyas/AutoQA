# Contributing to AutoQA

Thank you for your interest in contributing to AutoQA! This guide covers the basic workflow for making improvements and submitting pull requests.

## How to Contribute

1. Fork the repository on GitHub.
2. Clone your fork:
   ```bash
   git clone https://github.com/04-shreyas/AutoQA.git
   cd AutoQA
   ```
3. Create a new branch for your work:
   ```bash
   git checkout -b feature/your-feature
   ```
4. Make your changes, then add and commit them:
   ```bash
   git add .
   git commit -m "Add feature description"
   ```
5. Run tests before submitting:
   ```bash
   pytest tests/
   ```
6. Push your branch and open a pull request.

## Guidelines

- Keep changes focused and easy to review.
- Add or update tests for new behavior.
- Update documentation when adding features or changing workflows.
- Follow existing formatting and style patterns.

## Reporting Issues

If you find a bug or want to request a feature, please open an issue on GitHub with a clear description and reproduction steps.
